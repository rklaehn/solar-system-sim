HEEO refueling

I have thought about this for a while. Not sure if going too deep into math initially is that useful. Let's instead start by simplifying the problem.

The HEEO orbit can be any shape or size, so we can put it somewhere that makes TLI simpler and cheaper. We can put it into the orbital plane of the moon, and align the line of apsides of the HEEO so that the apogee of our HEEO points toward the perigee of the moon.

Now we make the orbital period of the HEEO a fraction of the lunar orbital period. We can then adjust the orbit so that we have one TLI launch window per month, when we are at perigee of the HEEO for maximum Oberth effect.

Let's choose 1/28, so it is about a day long. We can choose the perigee to be anything, so let's choose the perigee of a low LEO, say 200km.

The orbital plane of our HEEO will undergo a bit of precession, but that amount is very low since the effect of the Earth oblateness is not felt as much most of the orbit. The orbital plane can be kept in sync with the lunar orbital plane with tiny plane change maneuvers at apogee. The required delta-v is small enough that electric propulsion would be completely sufficient.
